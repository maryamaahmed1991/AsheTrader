# Ashe's helpers

Five transparent, 256 × 256 exports of the owner's selected character artwork, generated with the built-in image generator using their FFXIV character reference. Original high-resolution candidates are retained in the workspace outside the release package.

Welcome accompanies connection help; Parcel accompanies transfer help; Coin accompanies store help; Fuel accompanies fuel help; Cozy accompanies search and general guidance. Illustrations appear only inside explicitly opened help popups.

These files are bundled with the plugin. No image downloads occur at runtime. `MascotArt` uses Dalamud's shared texture cache and borrows wrappers only for the current frame. Artwork is requested only while a help popup is open. Missing artwork falls back to an AT badge without hiding help text. The popup illustrations can be hidden in Advanced preferences.
