# Ashe's helpers

Five transparent, 256 × 256 exports of the owner's selected character artwork, generated with the built-in image generator using their FFXIV character reference. Original high-resolution candidates are retained in the workspace outside the release package.

Welcome accompanies connection setup; Parcel accompanies jobs and store setup; Coin is the brand/store portrait; Fuel accompanies fuel queues; Cozy accompanies search and general guidance.

These files are bundled with the plugin. No image downloads occur at runtime. `MascotArt` uses Dalamud's shared texture cache and borrows wrappers only for the current frame. Missing artwork falls back to an AT badge without hiding help text. The illustrations can be hidden in Advanced preferences.
